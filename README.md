### 📖 Sobre o Projeto

Este é um sistema de linha de comandos desenvolvido em Python para a gestão de um catálogo de restaurantes. A aplicação permite o cadastro de novos estabelecimentos, a listagem dos dados cadastrados e a alteração dinâmica do status de atividade de cada restaurante (ativo/inativo).

### ✨ Funcionalidades

- **Cadastro de restaurantes:** Inserção do nome e da categoria gastronômica do estabelecimento.
- **Listagem formatada:** Exibição clara e alinhada de todos os restaurantes, categorias e seus status atuais (Ativado/Desativado).
- **Alternância de status:** Permite ativar ou desativar um restaurante através de uma busca pelo nome.
- **Tratamento de exceções e erros:** Uso de blocos `try-except` para evitar que a aplicação encerre inesperadamente ao receber dados inválidos.
- **Match-Case:** Utilização de estruturas modernas do Python (`match-case`) para o controle do menu de navegação.
- **Documentação interna:** Código organizado com funções bem definidas e documentadas com `docstrings`.

## 🇺🇸 English Version

### 📖 About the Project

This is a command-line system developed in Python for managing a restaurant catalog. The application allows for the registration of new establishments, listing of the registered data, and dynamically toggling the activity status of each restaurant (active/inactive).

### ✨ Features

- **Restaurant Registration:** Input the name and gastronomic category of the establishment.
- **Formatted Listing:** Clear and aligned display of all restaurants, categories, and their current status (Activated/Deactivated).
- **Status Toggling:** Allows activating or deactivating a restaurant by searching for its name.
- **Exception and Error Handling:** Use of `try-except` blocks to prevent the application from crashing unexpectedly when receiving invalid data.
- **Match-Case:** Utilization of modern Python structures (`match-case`) for navigation menu control.
- **Internal Documentation:** Organized code with well-defined functions documented using `docstrings`.
